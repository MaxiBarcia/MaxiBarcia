### 👨‍💻 Sobre mí

Apasionado por la ciberseguridad con una visión **360 grados**: entiendo el ataque para defender mejor y conozco la defensa para anticipar ataques.

*   🔴 **Red Team / Pentesting**: Pruebas de intrusión, evaluación de vulnerabilidades, simulación de adversarios. Escribo **writeups técnicos** de cada máquina que resuelvo.
*   🔵 **Blue Team / SOC**: Monitoreo de amenazas, análisis de logs, respuesta a incidentes y hardening de sistemas.
*   💻 **Desarrollo**: Construyo mis propias herramientas. Sólidos conocimientos en **Python, C y JavaScript**.
